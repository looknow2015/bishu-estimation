# 比数 · 20题原创配图

这套配图由内置 imagegen 生成，以蓝白色软质立体图标为主。每个图标只表达题意，不表示答案中的真实数量、比例、频率、尺寸或重量。

- `originals/`：20个透明背景 PNG 原图。
- `../dist/assets/`：保持透明度的 WebP 网页版。
- `manifest.json`：原图与网页文件的对应关系。
- `prompts.json`：各题使用的生成提示词。

第9、10、11、15题在网页中使用短暂的 CSS 动效；素材本身是静态图，动画不表示实际舔舐、膨胀、气泡产生或眨眼的频率。动效最多播放两次，且遵循“减少动态效果”设置。

第19题采用原创融化钟图标，未复制达利的《记忆的永恒》。它是题材提示，不是原作缩略图。

本地试玩版已内嵌全部配图，可以离线打开。生成提示词和原图同时保存，方便后续调整。
